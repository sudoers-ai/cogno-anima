# NOUMENO — perception and normalisation

Moved verbatim from `CLAUDE.md` on 2026-11-08: the contract did not change. `CLAUDE.md` keeps a short summary and points here. Update this file in the same pull request as any change to the NOUMENO stage, as `CLAUDE.md` used to be updated.

1. **NOUMENO** (`cogno_anima/stages/noumeno.py`, class `Noumeno`) — perception/normalization:
   - Expands slang via `expand_slangs` (utils)
   - Resolves language by precedence: per-request `ctx.force_language` (the tenant/session language) → stage `default_language` (host/global config, e.g. the SaaS sets `Noumeno(default_language="pt-BR")`) → `langdetect` fallback. The library ships no business default (`default_language=None`); `langue` in NER is inherited from this resolved `noumeno.language`
   - Checks subject continuity against `ctx.metadata["last_rewritten"]` using an `Embedder` (cosine similarity vs `subject_threshold`)
   - Calls the LLM to rewrite input into canonical English, returning JSON (`rewritten`, `context_turn`, `confidence`, `changed`, `preserved_terms`, `rewrite_warnings`). **A preserved E-MAIL or URL the contact never typed is DROPPED before it reaches the judge or the voice (2026-09-22)** — measured 3/3 (qwen3:8b, `temperature=0`) on the host's onboarding cassette (#954): the contact's address came back under `preserved_terms` with one character altered, and since the judge demands the exact reproduction of every preserved VALUE (#172) every reply carrying the RIGHT address was rejected for "altering" it. Only e-mails and URLs (`cogno_anima.preserved.EXACT_TOKEN_RE`, the exact-token half of the SAME `CRITICAL_TERM_RE` the judge reads — one definition, moved out of `superego.py`): a FIGURE is normalised on the way to English («R$ 1.000,00» → `1000`) and a preserved term is a VALUE, not a spelling, so figures, names and phrases never take this path. The comparison is a whole-address match against the RAW `ctx.user_input` (never the rewrite, which carries the same mutation), case included — a false drop costs only the marking, a false keep is the measured defect. The mark: `vocab.PRESERVED_NOT_IN_INPUT` on `degradations`, the COUNT on `NoumenoResult.preserved_dropped`, `NOUMENO.PRESERVED_NOT_IN_INPUT` in `to_tags()` (via `DriftMetrics.noumeno_degradations`), and a WARNING with the count — never a value (PII). `tests/unit/test_preserved_terms_are_the_contacts.py` pins the twin, the three controls and the comparison's edges.
   - Computes `drift_score` = `1 - cosine(embed(original), embed(rewritten))` and classifies it via `classify_drift()` into `PASS_THROUGH | REWRITTEN | COMPRESSED | EXPANDED | DRIFT` (reconciliation rule: drift > 0.50 forces `changed=True` and tag `DRIFT`)
   - **An embedder failure NEVER kills the turn — and the drift it could not take is `UNKNOWN`, a third state that is neither 0.0 nor 1.0.** Measured in production 2026-09-06: 2 accepted contact messages of 274 (0.73%) over 23.28 h produced no turn at all — no row in `turns`, none in `turn_traces` — both landing under a second past the embedding client's 120 s read timeout while every 200 in the same windows finished under 86 s. The `httpx.ReadTimeout` came out of `_similarity` and crossed `process` untouched. Both call sites now degrade independently (`vocab.EMBED_UNAVAILABLE` on `NoumenoResult.degradations`, a WARNING, `embedding_calls` still counted because the round trip happened): `subject_similarity=None` with `change_subject=False` (assume continuity — the first-turn value, and the conservative side, since `True` DROPS the thread's carry-over), and `drift_score=None` with `drift_tag="UNKNOWN"`, the reconciliation skipped so `changed` keeps what the rewriter itself said. **Why not 0 or 1:** 0.0 reads as *verified, nothing drifted* and waves through a turn nobody checked; 1.0 reads as *total drift*, forces the `DRIFT` tag and can trip a `self_correct` over a turn that was fine. The third way needed no new machinery — `DriftMetrics` already documents `None` as "stage not computed yet (distinct from 0.0 = computed, no drift)" and `compute_cumulative` already renormalized over the non-`None` components; the epistemological one was simply the ONE that could not say it, which is exactly the one an embedder outage destroys. `to_tags()` emits `NOUMENO.DRIFT_UNKNOWN` so a reader of tags alone cannot mistake the absence of `NOUMENO.DRIFT` for a pass. **The line this draws** (and why `generate_json_resilient` still re-raises, deliberately): the LLM **produces** the rewrite the whole pipeline consumes, the embedder only **measures** it — losing the product must be loud, losing a measurement must be recorded AS an absence and never as a value. `asyncio.CancelledError` still unwinds (`except Exception`, not `BaseException`). The ID stage already made this choice (`routing/goal.py` degrades any embedder failure to Jaccard) and so does `cogno_synapse.OllamaEmbedder` in its own docstring.
   - Populates `ctx.noumeno: NoumenoResult`
